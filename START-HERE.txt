ETS: START HERE
===============

This folder is a complete copy of the site: the map, the editor hub, and the Franklin County sample data
(places, photos, tours, stamps). Nothing else is needed.

WHAT IS WHAT
  Demo2a.html     the map visitors use.  index.html (the home address) forwards to it.
  tabs.html       the editor hub: where you change everything. Open it on your site, not from a file on your computer.
  *.csv           your data: places, spots, tours, stamps, categories, settings, announcements.
  icons.js        the little pictures on markers, stamps and tours.
  photos/ spots/ stories/ anims/   your pictures and animations.
  events/         saved events (empty at first).
  archive/        old and unused files. Safe to delete.

PUT IT ON THE INTERNET (GitHub Pages)
  1. Make a new repository on github.com and upload everything in this folder (the files, not the folder around them).
  2. In the repository: Settings > Pages > publish from the main branch.
  3. After a minute your site is at  https://YOURNAME.github.io/REPOSITORY/
     The map opens at that address. The editor hub is at  .../tabs.html

THE FIRST TEN MINUTES (try these in the hub, tabs.html)
  1. Look at the map. Watch the welcome screen, then press Tours & Trails and try a time button (30 min, 1 hour...).
  2. Check My Data tab > Run. It lists anything that would quietly break the map. On the sample data it reports one
     problem (a stamp lists a task that does not exist) and a few warnings. That is leftover demo data.
  3. Announcements tab > + New announcement. Give it a name, a short tag, a color and a sentence. Tick a place.
     Set dates that include today. The preview shows what visitors will see. Download, then upload the file
     (or Publish, below). Reload the map: it is on the welcome screen with its tag.
  4. Tours and Trails tab > pick a tour > tick "Feature this on the welcome screen..." and fill in the short description.
     It joins the welcome screen and the Events panel, and is listed first in the tour list.
  5. Back in Announcements, use "Feature a tour or trail" so an announcement gets a Start the tour button.
  6. Calendar tab: see announcements and events on a month grid or a list. Conflicts are flagged in red.
  7. Icons tab: pick an icon and draw or edit it, Save icon, then download icons.js.

PUBLISH FROM THE HUB (optional)
  Each editor has a Download button. You can upload what it gives you by hand. Or use the Publish button: it saves all
  your changes straight to GitHub. Its settings window tells you how to make the access token it needs. A token is a
  password: never put it in a page or share it.

MAKE IT YOURS
  Site Settings tab: the name (PLACE), colors, welcome picture, map start view and boundaries.
  manifest.json and the icon-*.png files still say Franklin County (the name when someone installs the map as an app).
  welcome1.gif is the welcome picture; the sample places and photos are Franklin County's. Replace them as you go.

WHAT HAS NOT BEEN TESTED
  This package has been loaded page by page in a test browser, and its editors and checker have been exercised there.
  The full map page with live map tiles, the Tours editor, and the Publish button have not been run end to end by me.
  If something looks wrong, tell me what you see.
