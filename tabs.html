Welcome to the Editing Hub! Select any of the tabs above to edit basic information and settings for that function. Each tab auto-loads its assigned CSV or JSON files from the main folder. This allows you to edit visually by dragging pins, ticking checkboxes, setting thresholds, and aligning images. Using the Download Updated button on the tab will download the updated file to your computer. Upload that file back into your hosting site in the same place from which it came. The live site view will update itself once the updates are published and loaded.

Publish

Every editor keeps its own changes until you publish. This page gathers them all, shows what changed, and publishes them together.

Restore a Previous Version

Made a mistake? This brings your data files (places, spots, tours, settings and so on) back to how they were at an earlier publish. Photos are left alone. It adds a new version on top, so nothing is lost and you can undo it the same way.
